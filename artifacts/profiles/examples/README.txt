Grim Gleaner example profiles

These are approximate starter profiles, intended to demonstrate how to think about weights.

Each profile is based on a build guide from GrimTools, but they are not optimized build guides and are meant to be customized or simply used as an example for customizing your own builds.

Coverage:
- Acid / Poison: Dervish (Nightblade + Oathkeeper)
- Aether: AAR Spellbinder (Arcanist + Necromancer)
- Pierce / Bleed: Crit Reaver (Nightblade + Berserker)
- Fire / Burn: Vire's Might Shieldbreaker (Demolitionist + Oathkeeper)
- Chaos: Callidor's Tempest Warlock (Occultist + Arcanist)
- Cold / Frostburn: TSS Spellbreaker (Nightblade + Arcanist)
- Physical / Internal Trauma: Blade Arc Warlord (Soldier + Oathkeeper)
- Vitality / Vitality Decay: Conjurer (Occultist + Shaman)
- Elemental: PRM Mage Hunter (Arcanist + Inquisitor)
- Lightning: Lightning Vindicator (Shaman + Inquisitor)
- Bonus: Chaos Pets Deceiver (Occultist + Inquisitor)
